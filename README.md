# raid-calculator

Calculadora web para planificar cuentas de RaidLords: metas de retiro, niveles de Royal Mint, minería necesaria, esencia, costos y ganancia estimada.

## Uso

Abrí `index.html` en el navegador. No necesita instalación, servidor ni dependencias.

## Funciones

- Simulador de cantidad de cuentas y meta de retiro diaria.
- Plan de minería y esencia necesarios para cada meta.
- Comparación de niveles de Royal Mint, costos y ganancia estimada.
- Ruta de compra ordenada: entrada, Keep, minas, Mint y cobros.
- Diseño responsive y tema claro.

## Datos

Basado en la calculadora por Mint y en la RaidLords Handbook. Los precios, límites y reglas pueden cambiar.

## Aviso

Modelo educativo. No es asesoramiento financiero.
